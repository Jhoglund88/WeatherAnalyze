# WeatherAnalyze
Ett Pythonprojekt som hämtar väderdata via ett API och analyserar insamlad data.

## Mål
Mitt mål är att göra en enkel väderapp där användaren genom en meny får välja en stad som den vill hämta väderinfo om. Därefter så ska väderdata hämtas med hjälp av ett API-anrop och sedan sparas ner i JSON-format för att senare kunna bearbetas, analyseras och visualiseras.

## Metod
1. Låta användaren välja en stad att hämta väderinfo om samt välja om detaljerad infomation ska visas.
2. Hämta väderinfon från Open-Meteo API med hjälp av Python biblioteket `requests`.
3. Spara den hämtade datan i en JSON-fil.
