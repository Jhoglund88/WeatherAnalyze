# WeatherAnalyze
Ett Pythonprojekt som hämtar väderdata via ett API och analyserar insamlad data.

## Mål
Mitt mål är att göra en enkel väderapp där användaren genom en meny får välja vad den vill få information om. Därefter så ska väderdata hämtas med hjälp av ett API-anrop och sedan sparas ner i en CSV-fil.
